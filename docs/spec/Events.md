# Spec: Events

> **版本**：v0.1.6（与 `eng/Observables.Package.props` 对齐）
> **关联 Design Doc**：[docs/design/events.md](../design/events.md)
> **关联 ADR**：—

## API 面

### NuGet 包

| 包 ID | 后端 | 运行时 |
|-------|------|--------|
| `Observables.Events.R3` | R3 | 无（纯生成；仅 MSBuild props） |
| `Observables.Events.Reactive` | System.Reactive | 无 |

### 入口扩展方法（按使用即生成）

| 方法 | 返回形状 | 场景 |
|------|----------|------|
| `.Events()` | `Observable<T>` / `IObservable<T>` | 事件载荷，去掉 `sender` |
| `.EventHandlers()` | `Observable<(object? sender, TEventArgs e)>` | 保留 `sender` 与 `EventArgs` |
| `.RoutedEvents()` | `Observable<T>` | WPF/Avalonia 路由事件（须开启开关） |
| `.RoutedEventHandlers()` | `Observable<(object? sender, TEventArgs e)>` | 路由事件保留 sender |
| `.AttachedRoutedEvent<T>()` | `Observable<TEventArgs>` | 附加静态路由事件字段 |
| `.AttachedRoutedEventHandler<T>()` | `Observable<(object?, TEventArgs)>` | 附加路由事件 + sender |

生成器产出：`IEventsInterface_<Type>`、`EventsImpl_<Type>`、bootstrap 扩展方法；桥接类型 `EventObservable`、`NullEvents` 为 `internal`。

### MSBuild 配置

| 属性 | 默认 | 说明 |
|------|------|------|
| `ObservableRoutedEvents` | `false` | `true` 时启用路由事件相关入口 |
| `UseWPF` | 自动检测 | 影响 WPF 路由事件识别 |

定义于 `Observables.Events/targets/observables.events.props`。

### 检测规则（契约）

- **经典事件**：类型上任何 `event` 成员（含继承）。
- **路由事件**：实例事件对应静态字段 `{Name}Event`，类型为 WPF / Avalonia `RoutedEvent`（或泛型变体）。
- **附加路由事件**：调用方显式传入静态 `RoutedEvent` 字段引用。

## 诊断 ID

| ID | 级别 | 触发条件 | helpLinkUri |
|----|------|----------|-------------|
| OBS2001 | Warning | `.Events()` — 不支持的委托签名 | `…/diagnostics.html#obs2001` |
| OBS2002 | Warning | `.EventHandlers()` — 非 EventHandler / `(object, T)` 形态 | `#obs2002` |
| OBS2003 | Warning | `.RoutedEvents()` — 不支持的路由委托 | `#obs2003` |
| OBS2004 | Warning | `.RoutedEventHandlers()` — 不支持的路由处理器 | `#obs2004` |
| OBS2005 | Error | Events 源生成器内部错误 | `#obs2005` |

类别：`Observables.Events`。用户向说明见 [Observables.Docs — Events diagnostics](https://skymly.github.io/Observables.Docs/diagnostics.html#obs2001)。

OBS2001–2004 为 Warning：跳过该事件，不阻塞编译。OBS2005 为 fail-safe 内部错误。

## 不变量

1. Events 域**无公共运行时类型**；消费者仅引用 NuGet 包即可获得生成器与 props。
2. R3 与 Reactive 包**不得**同时作为同一功能域的依赖（共享分析器 OBS0001 适用全库）。
3. 生成代码均带 `// <auto-generated/>` 头（`GeneratedSourceHeader`）。
4. 路由事件生成默认关闭，避免未使用 WPF/Avalonia 的项目引入路由 API。
5. 未发现事件时 `.Events()` 回退 `NullEvents`，保持编译通过（非运行时异常）。

## 兼容基线

- 生成器 TFM：`netstandard2.0`（Roslyn 组件）
- 消费者：任意支持源生成器的 .NET 项目；路由事件需引用 WPF 或 Avalonia
- 静态事件生成：当前关闭（`StaticObservableEventsGenerationEnabled = false`）

## 不在范围内

- 跨程序集事件发现（当前仅本程序集）
- 第三反应式后端（见 [ADR-001](../adr/ADR-001-primitives-backend-skip.md)）
- 路由 `RoutingStrategies` 强类型（当前以 `object` 传递）
